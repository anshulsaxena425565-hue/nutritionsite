# Prachi Sayani — Nutrition Landing Page

A responsive, single-page landing page for Prachi Sayani, built with semantic HTML, CSS, and vanilla JavaScript.

## Features
- Responsive layout for mobile, tablet, and desktop
- Animated reveal-on-scroll sections and floating decorative elements
- Mobile navigation
- About, areas of interest, approach, education, and contact sections
- Accessible contact form with basic validation and submission status

## Contact form setup
The form uses FormSubmit and is configured for **anshulsaxena425565@gmail.com**.

1. Deploy the site and submit a test enquiry.
2. FormSubmit may send an activation/confirmation email to the destination inbox on first use. Open that email and activate the form.
3. Submit another test to verify delivery. Check spam/junk if the activation message does not appear.

The form depends on FormSubmit's external service and therefore requires an internet connection. Do not include sensitive health information in the initial enquiry.

## Deploy
This is a static site; no build step or package installation is required.

- **Vercel:** Import this repository as a new project. Framework preset: Other. Build command: leave empty. Output directory: `.`.
- **GitHub Pages:** In repository Settings → Pages, deploy from the `main` branch and the root folder.
